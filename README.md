# Jev Moral Railway

選択済みのネオン番組風デザインを使う、3問のトロッコ問題ゲームです。
「ゲームをプレイ」を押すと、運転手Jevが進路を判定します。画面はJevの運転席視点で、分岐器が回答の方向へ動いてから、レールに沿って加速・走行します。人たちへの衝突を短い暗転で示し、次の分岐・質問へ自動で進みます。プレイヤーが2択を選ぶ操作はありません。
前方の人数は問題ごとに5人/1人、4人/1人、2人/1人へ切り替わります。3問それぞれでプレイし、最後にJevの3つの判断と結果を振り返ります。デモとTypeSafe API判定を明示的に切り替えます。正解を採点するゲームではありません。

## 開発場所

プロダクトは `~/dev/jev-trolley-game` で管理します。専用の `.git` を使い、Vaultは記録・参照専用です。移行元のコード・画像は削除していません。依存関係は新しい場所で `npm ci` により取得済みです。

## APIキーの保存先

このREADMEと同じフォルダーの `.env.local` に、次の1行を設定します。

```dotenv
TYPESAFE_API_KEY=ここを発行したAPIキーに置き換える
```

キーは [TypeSafe Console](https://console.typesafe.ai/) で発行します。
設定後は開発サーバーを再起動してください。ゲームは最初はデモモードです。
プレイボタンの上にある判定モードで「TypeSafe API（残高を使用）」を選び、「ゲームをプレイ」を押すと実際の判定を1回依頼します。
モードは運行を始めたゲーム中は固定です。次の問いは衝突後に自動で現れますが、再びプレイを押すまでAPIを呼びません。再プレイはデモに戻ります。
起動時の設定確認は外部APIを呼びません。「キー設定あり」は認証・残高確認済みの意味ではありません。

`.env.local` はGit対象外です。`src/`・`public/`・チャットにキーを書かず、`VITE_` を変数名に付けないでください。
Gitの除外設定は暗号化ではありません。iCloud同期フォルダー内に置く場合、このファイルも同期され得ます。
同期を避けたい場合は `.env.local` を空のままにし、通常のターミナルで入力を伏せて環境変数を渡せます（zsh）。

```zsh
read -rs 'TYPESAFE_API_KEY?TypeSafe API key: '
export TYPESAFE_API_KEY
npm run dev
```

## ブラウザで開く

Node.js 22.12以降が必要です。このプロジェクトのフォルダーをターミナルで開き、初回のみ依存パッケージを取得します。

```sh
npm ci
npm run dev
```

起動成功後に [http://127.0.0.1:5173](http://127.0.0.1:5173) を開きます。
`index.html` のダブルクリックでは動きません。Reactの変換と、キーを非公開にしたAPI中継を開発サーバーが担当するためです。
サーバーはこのMac内だけに公開され、停止するにはターミナルで Control+C を押します。
5173番が使用中なら、別の番号で起動せず既存のこのゲームのサーバーを確認してください。

## 動作と料金

- デモモードは外部通信なし（起動時のローカル設定確認を除く）。Jev・投票の値は固定の架空サンプルです。
- APIモードは問題文・2択だけをTypeSafeへ送信します。個人ファイルは送りません。
- 判定の自動再送・自動チャージは実装していません。失敗時も課金有無はTypeSafeの利用明細で確認してください。
- 確信度は選択肢間の確率の偏りを表す値で、倫理的な正しさの割合ではありません。
- Jevは説明文を生成しないため、架空の「判断理由」を本人の発言として表示しません。
- 5ドルの初回無料枠は、2026-09-19時点で確認した公式公開資料では裏付けを取得できていません。付与額・期限は自分のConsoleに表示されるクレジット残高と条件を確認してください。

公式資料: [Quick start](https://docs.typesafe.ai/introduction/quickstart)、[Choice](https://docs.typesafe.ai/primitives/choice)、[Models](https://docs.typesafe.ai/models)。

## 線路の描画

Three.jsで線路・枕木・可動ポイントを描画します。カメラは同じ線路の中心を距離に沿って進み、加速・減速します。起動にはWebGL対応ブラウザが必要です。描画失敗時は案内を出し、プレイを無効にします。画素密度を最大1.5倍に制限し、停止中は連続描画しません。OSの「視差効果を減らす」設定では連続走行を省略します。この設定の実画面確認は未実施です。

3D描画を含むJS配信量は約757kB（gzip約204kB）で、Viteの500kB警告が出ます。ビルド失敗ではありません。景色・人物はゲーム用の図像で、鉄道物理や制動距離を再現するシミュレーターではありません。
