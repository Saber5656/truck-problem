# Jev Moral Railway

選択済みのネオン番組風デザインを使う、3問のトロッコ問題ゲームです。
初期画面は「トロッコ問題を遊ぶ」というスタート画面です。問題や選択肢はまだ表示しません。
「ゲームをプレイ」を1回押すと、第1問が現れ、Jevが**犠牲にする相手（轢く側）**を選び、3問を続けて運行します。選んだ人たちがいる線路へ分岐器を切り替え、運転席視点で進みます。衝突を短い暗転で示した後、走りながら次の問いを判定します。
問題は「ニート5名／科学者1名」「見知らぬ5名／あなたの家族1名」「爆弾を仕掛けた5名／唯一の解除技師1名」。将来の貢献と人数、身内と公平さ、目の前の救助とその先の被害を天秤にかける架空の思考実験です。3問目では、技師が生き残れば乗客100名を確実に救え、技師が死ねば100名も死亡し、代替手段はないと設定しています。質問・選択肢はデモと実APIで共通です。全問で左の直進側に5人、右の分岐側に1人がいます。レバーを動かさなければ左の5人を轢き、意図的に切り替えると右の1人を轢きます。
**質問と質問の間は停止しません。** 通常の分岐間は元の長さに短い余裕を加え、通常は約26秒で3問から終点まで進みます（API待ち時間を除く）。判定が遅い場合や通信エラー中だけ短い直線を追加して走行を続けます。エラー時は画面の「もう一度判定する」で再試行できます。判定を捏造したり、未決定の分岐へ進んだりしません。
全3問の後、終点駅で初めて減速・停車します。停車すると自動で結果画面に移り、犠牲になった人・助かった人・確率・確信度を振り返れます。正解を採点するゲームではありません。

## 開発場所

プロダクトは `~/dev/jev-trolley-game` で管理します。専用の `.git` を使い、Vaultは記録・参照専用です。移行元のコード・画像は削除していません。依存関係は新しい場所で `npm ci` により取得済みです。

## APIキーの保存先

このREADMEと同じフォルダーの `.env.local` に、次の1行を設定します。

```dotenv
TYPESAFE_API_KEY=ここを発行したAPIキーに置き換える
```

キーは [TypeSafe Console](https://console.typesafe.ai/) で発行します。
設定後は開発サーバーを再起動してください。ゲームは最初からTypeSafe APIモードです。
「ゲームをプレイ」を押すと、3問を順に自動判定します（通常は最大3回、残高を使用）。通信なしで試す場合は、右上の「TypeSafe API」を開き、判定モードで「デモ（通信なし）」を選びます。
モードは運行を始めたゲーム中は固定です。次の問いは衝突後に自動で現れ、APIモードでは続けて判定を依頼します。通信エラーは自動再送せず、再試行ボタンを押したときだけ追加の判定を依頼します。再プレイはTypeSafe APIが選択されたスタート画面に戻ります。
起動時の設定確認は外部APIを呼びません。APIモードを選べることは認証・残高確認済みの意味ではありません。

`.env.local` はGit対象外です。`src/`・`public/`・チャットにキーを書かず、`VITE_` を変数名に付けないでください。
Gitの除外設定は暗号化ではありません。iCloud同期フォルダー内に置く場合、このファイルも同期され得ます。
同期を避けたい場合は `.env.local` を空のままにし、通常のターミナルで入力を伏せて環境変数を渡せます（zsh）。

```zsh
read -rs 'TYPESAFE_API_KEY?TypeSafe API key: '
export TYPESAFE_API_KEY
npm run dev
```

## ブラウザで開く

Node.js 22.12以降が必要です。このプロジェクトのフォルダーをターミナルで開き、初回のみ依存パッケージを取得します。

```sh
npm ci
npm run dev
```

起動成功後に [http://127.0.0.1:5173](http://127.0.0.1:5173) を開きます。
`index.html` のダブルクリックでは動きません。Reactの変換と、キーを非公開にしたAPI中継を開発サーバーが担当するためです。
サーバーはこのMac内だけに公開され、停止するにはターミナルで Control+C を押します。
5173番が使用中なら、別の番号で起動せず既存のこのゲームのサーバーを確認してください。

## 本番用ビルドで実APIを試す

```sh
npm run build
npm start
```

[http://127.0.0.1:4174](http://127.0.0.1:4174) を開きます。ビルド済みの画面とサーバー側API中継を、この端末内だけで起動します。外部公開用のサーバーではありません。
キーは同じ `.env.local` の `TYPESAFE_API_KEY` をサーバー起動時に読み込みます。画面の初期状態はTypeSafe APIです。Playで3問を開始します。ページ表示やモード選択だけでは判定を送信しません。
キー設定を変更した場合は `npm start` のサーバーを再起動してください。公開用の認証・利用量制限・キー管理は別途必要です。

## 動作と料金

- デモモードは外部通信なし（起動時のローカル設定確認を除く）。判定・確率・確信度は固定の架空サンプルです。投票サンプルは表示しません。
- APIモードは問題文・2択だけをTypeSafeへ送信します。個人ファイルは送りません。
- 判定の自動再送・自動チャージは実装していません。失敗時も課金有無はTypeSafeの利用明細で確認してください。
- 確信度は選択肢間の確率の偏りを表す値で、倫理的な正しさの割合ではありません。
- Jevは説明文を生成しないため、架空の「判断理由」を本人の発言として表示しません。
- 5ドルの初回無料枠は、2026-09-19時点で確認した公式公開資料では裏付けを取得できていません。付与額・期限は自分のConsoleに表示されるクレジット残高と条件を確認してください。

公式資料: [Quick start](https://docs.typesafe.ai/introduction/quickstart)、[Choice](https://docs.typesafe.ai/primitives/choice)、[Models](https://docs.typesafe.ai/models)。

## 線路の描画

Three.jsで線路・枕木・可動ポイントを描画します。カメラは同じ線路の中心を距離に沿って進みます。最初だけ加速し、途中は一定速度、最後の駅だけで減速します。起動にはWebGL対応ブラウザが必要です。描画失敗時は案内を出し、プレイを無効にします。画素密度を最大1.5倍に制限し、停止中は連続描画しません。OSの「視差効果を減らす」設定では、進行時間は維持したままカメラの連続移動を省略します。この設定の実画面確認は未実施です。

3D描画を含むJS配信量は約765kB（gzip約207kB）で、Viteの500kB警告が出ます。ビルド失敗ではありません。景色・人物はゲーム用の図像で、鉄道物理や制動距離を再現するシミュレーターではありません。

画面はデモと実APIで共通です。通常の画面は質問・運転席・2択・判定・再生操作に絞り、モードとAPI利用回数の説明は右上にまとめています。開発用のキー設定手順は画面から外し、このREADMEで管理します。
